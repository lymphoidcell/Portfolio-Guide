## Machine Learning – Project Showcase

I’ve divided my machine learning projects into eight levels based on these factors:
* Depth of theoretical understanding
* Engineering complexity
* Project scope and integration
* Compute and data scale
* Research and production orientation

2. Classic ML Projects
3. Deep Learning

5. Sequence & NLP Models
6. Transformers & Generative Models
